# Орлин Цветанов — цигулар

Подготвено копие на публичния сайт за GitHub Pages. Целеви адрес: https://orlintsvetanov.github.io/
Архивът не доказва, че домейнът е регистриран или че сайтът е публикуван там.

## Публикуване

1. Качете съдържанието на тази папка в корена на публично GitHub хранилище, клон main.
2. В Settings → Pages изберете Deploy from a branch, main, /(root).
3. Проверете страницата на получения от GitHub адрес. Изображенията, шрифтовете и споделените стилове използват относителни адреси и работят и в проектна подпапка.
4. Регистрирайте домейна на собственика. В личните GitHub Settings → Pages добавете домейна за проверка и запазете точния издаден TXT запис при регистратора.
5. След потвърдена собственост задайте orlintsvetanov.com в Settings → Pages → Custom domain. GitHub ще добави CNAME при публикуване от клон. Едва след това насочете DNS към GitHub Pages.
6. За основния домейн A записите са 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153. За www използвайте CNAME към реалното ПОТРЕБИТЕЛСКО_ИМЕ.github.io, без името на хранилището. Проверете текущите официални инструкции преди промяната. Не променяйте MX записите за имейл.
7. След готов сертификат включете Enforce HTTPS. Проверете основния адрес, www, двата езика, снимките, видеото и записването през Google Calendar.
8. Подайте новата карта на сайта в Google Search Console. Старият адрес се пренасочва едва след успешно пускане на новия.

Вариантите за сравнение на дизайна, вътрешните бележки, историята на разработката и настройките на стария хостинг не са част от това копие.
Формулярът подготвя имейл в приложението на посетителя; няма сървър за изпращане. Записването за уроци остава в Google Calendar.

## Условия и разходи

GitHub Pages е наличен без платен план за публични хранилища. HTTPS за правилно настроен собствен домейн е включен. Домейнът се плаща отделно и се подновява ежегодно.
GitHub ограничава употребата на Pages за онлайн бизнес и сайтове, насочени основно към търговски сделки. Това копие запазва артистичното портфолио и всички одобрени услуги; само липсата на онлайн плащане не доказва съответствие. Преценете приложимостта на условията преди активиране на хостинга.
